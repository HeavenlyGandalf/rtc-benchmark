# Лицензия на контент сайта — CC BY 4.0

Исходные файлы сайта документации (`docs/`, `mkdocs.yml`, материалы сайта в целом)
распространяются по лицензии **Creative Commons Attribution 4.0 International**
(CC BY 4.0).

Исходный код экспериментального стенда (`src/`, `scripts/`, `public/`,
конфигурация сборки) лицензируется отдельно — по лицензии MIT, см. [`LICENSE`](LICENSE).

## Кратко

| | |
|---|---|
| SPDX-идентификатор | `CC-BY-4.0` |
| Полный текст (legal code) | <https://creativecommons.org/licenses/by/4.0/legalcode.ru> |
| Простым языком (deeds) | <https://creativecommons.org/licenses/by/4.0/deed.ru> |

Разрешено копировать, распространять и перерабатывать материалы, в том числе
в коммерческих целях, при выполнении единственного условия: **указать авторство**.

## Что нужно указывать при использовании

Материал стенда распространяется на условиях CC BY 4.0. При копировании, публикации
или переработке необходимо указать:

- автора: **heavygendalf**;
- название: **rtc-benchmark: WebRTC и WebTransport**;
- ссылку на лицензию: <https://creativecommons.org/licenses/by/4.0/>;
- ссылку на источник — репозиторий проекта.

Допустимо, но не обязательно указать, что внесены изменения.

## Как соотносится с MIT

Одна лицензия на контент и другая на код — не конфликт, а разные режимы для
разных объектов в одном репозитории:

| Объект | Файлы | Лицензия |
|---|---|---|
| Код стенда | `src/`, `scripts/`, `public/`, `package.json`, `tsconfig.json` | [MIT](LICENSE) |
| Контент сайта | `docs/`, `mkdocs.yml`, `README.md` | CC BY 4.0 (этот файл) |
| Зависимости | `yarn.lock`, `requirements.txt` | собственные лицензии авторов, см. `LICENSE-*` в каталогах зависимостей |

Файлы не смешиваются: страница сайта — это контент, скрипт стенда — это код, и на
страницу из `docs/` не попадает ни строки TypeScript, а в бандл `public/app.js`
не попадает ни строки документации.

Полные тексты лицензий зависимостей поставляются вместе с пакетами: в Yarn — в
`.yarn/cache`, в Python-окружении — в `.venv-docs/lib/python3.14/site-packages/`.
