# rtc-benchmark

Экспериментальный стенд к НИР «Сравнительный анализ технологий WebRTC и WebTransport
для передачи данных в реальном времени в веб-приложениях».

Стенд измеряет **WebRTC** и **WebTransport** на одинаковых сценариях и по одинаковым
метрикам: время установления соединения, задержку обмена (RTT) и её разброс, потери,
пропускную способность, а также видеотрансляцию через сервер
(камера → транспорт → эхо-сервер → экран).

Сайт документирует методику, устройство стенда и порядок работы с ним. Он собран
на [MkDocs Material](https://squidfunk.github.io/mkdocs-material/): исходники страниц
лежат в каталоге `docs/`, конфигурация — в `mkdocs.yml` в корне репозитория.

## Сравниваемые технологии

| Транспорт | Каналы данных | Транспортный уровень | Медиастек |
|---|---|---|---|
| WebTransport | надёжный двунаправленный поток QUIC, ненадёжные дейтаграммы QUIC | HTTP/3 поверх QUIC | в приложении (WebCodecs) |
| WebRTC | надёжный и ненадёжный каналы данных поверх SCTP | DTLS поверх ICE (UDP) | встроенный в браузер |

Подробное описание каждой технологии — на страницах [WebRTC](webrtc.md) и
[WebTransport](webtransport.md).

## Быстрый старт

```bash
corepack enable          # один раз: активировать Yarn 4 из package.json
yarn install             # зависимости + нативный модуль QUIC
yarn start               # сборка клиента и запуск стенда
```

Стенд открывается на <http://localhost:8080>. Полный порядок запуска, команды,
переменные окружения и диагностика — на странице
[Как запустить стенд](running.md).

!!! warning "Репозиторий не содержит результатов измерений"
    Стенд не сохраняет замеры в репозитории: результаты живут в браузере до
    экспорта в CSV. Поэтому на сайте нет числовых таблиц измерений — есть
    методика, состав метрик и порядок получения данных. Подробности в разделе
    [Результаты](results.md).

## Ограничения

Ключевое ограничение — измерения выполняются на loopback: клиент и сервер
работают на одном хосте, реальная сеть, MTU, задержка и потери не
моделируются. Полный список — на странице [Ограничения](limitations.md).
