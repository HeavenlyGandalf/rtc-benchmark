# MathJax, вложенный в репозиторий

Здесь лежит локальная копия MathJax: сайт рисует формулы сам, не обращаясь
ни к какому внешнему хосту.

| | |
|---|---|
| Пакет | `mathjax` 3.2.2 из реестра npm |
| Файл | `tex-svg.js` — сборка TeX + SVG-вывод |
| Лицензия | Apache-2.0, текст в `LICENSE-MATHJAX.txt` |
| SHA-256 файла | `d4295dc33744836935c1399feece5159577b34c5c8ffb9f1c6324cd82e03a882` |

Обновление: скачать `es5/tex-svg.js` и `LICENSE` из пакета той же версии,
положить их сюда и поправить номер версии и хеш в этой таблице.

## Почему файл в репозитории, а не ссылка на CDN

Сайт публикуется на закрытом хостинге ИТМО, где обращения к внешним CDN могут
быть недоступны или нежелательны. Обычная инструкция MathJax для MkDocs
подключает `https://unpkg.com/mathjax@3/es5/tex-chtml.js`; при таком подключении
страница с формулами выглядит рабочей при разработке и оказывается без формул
у посетителя — а это обнаруживается только на опубликованном сайте.

Поэтому скрипт лежит в репозитории и попадает в сборку сайта как обычный файл:
при `use_directory_urls: true` MkDocs переписывает ссылку на него в
относительную, и страница работает одинаково и на GitHub Pages, и на Helios, и
при локальном `mkdocs serve` без сети.

## Почему именно `tex-svg`, а не `tex-chtml`

Обе сборки — официальные, разница в способе отрисовки и в числе файлов:

* `tex-chtml.js` рисует формулы средствами HTML и CSS, но тянет за собой
  примерно три десятка файлов шрифтов WOFF;
* `tex-svg.js` рисует формулы сразу в SVG-пути, поэтому не требует ни одного
  дополнительного файла: один скрипт — и всё.

Для сайта, который должен открываться без внешних запросов, один файл в 2,1 МБ
предпочтительнее связки «скрипт плюс шрифты»: меньше запросов, меньше мест,
где может что-то сломаться.

## Настройка

Конфигурация загрузчика — `mathjax-config.js` рядом. Она объявляет разделители
`\(...\)` и `\[...\]`, которые выдаёт расширение
[`pymdownx.arithmatex`](https://facelessuser.github.io/pymdown-extensions/extensions/arithmatex/)
с опцией `generic: true`, и перезапускает отрисовку при мгновенной навигации
MkDocs Material. Сам `tex-svg.js` подключается в `mkdocs.yml` через
`extra_javascript` — порядок важен, конфигурация должна выполниться раньше
загрузчика.
